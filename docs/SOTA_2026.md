# JCUBE SOTA Gap Analysis — July 2026

**Date:** 2026-07-24
**Scope:** Where jcube stands relative to the current JEPA state of the art, what
this session adopted into the library, and what remains (with why).

---

## Where jcube stands

The library's research base before this session:

| Technique | Paper | Status in jcube |
|-----------|-------|-----------------|
| SIGReg (isotropic Gaussian regularization) | LeJEPA, [arXiv:2511.08544](https://arxiv.org/abs/2511.08544) (Nov 2025) | `regularizers.SIGReg`, used in trainers |
| RDMReg (rectified distribution matching) | Rectified LpJEPA, [arXiv:2602.01456](https://arxiv.org/abs/2602.01456) (Feb 2026) | `regularizers.RDMReg` |
| Weak-SIGReg (covariance-only) | [arXiv:2603.05924](https://arxiv.org/abs/2603.05924) (Mar 2026) | `regularizers.WeakSIGReg`, the V6.2 production loss |
| Dense temporal lookahead + xVal numeric encoding | V6.2 design (see `scale_pipeline_v6.py`) | Production pipeline on Modal |

Production model: V6.2 dense temporal JEPA (128-dim, Weak-SIGReg, 2-phase
curriculum) on the 35.2M-node / 165M-edge healthcare TKG.

## What the 2026 literature adds

Surveyed 2026-07-24:

1. **BiJEPA — Bidirectional JEPA with cycle consistency**
   ([arXiv:2603.00049](https://arxiv.org/abs/2603.00049), Mar 2026).
   Uni-directional prediction (context → target) discards the informative
   signal in the inverse relationship. BiJEPA trains forward and backward
   predictors jointly with cycle-consistency losses, and counters the
   resulting representation-explosion failure mode with norm regularization
   on the representation vectors. Demonstrated on periodic signals, chaotic
   Lorenz trajectories, and image data: stable convergence without collapse
   and without a stop-gradient/EMA teacher.

2. **SG-JEPA — Spiking JEPA for large-scale dynamic graphs**
   ([arXiv:2607.18412](https://arxiv.org/abs/2607.18412), Jul 2026).
   Temporal-window partitioning of graph snapshots (final snapshot = targets,
   preceding = context), GraphSAGE target encoder, spiking (PLIF) context
   encoder, InfoNCE alignment. 2.8–5.2× faster than contrastive/generative
   baselines by dropping edge reconstruction, negative sampling, and
   augmentation.

3. **TS-JEPA — Joint Embeddings Go Temporal**
   ([arXiv:2509.25449](https://arxiv.org/abs/2509.25449)). Time-series JEPA
   formulation; matches or surpasses SSL baselines on standard datasets.
   jcube's dense temporal lookahead (V6.2) already instantiates the same
   core idea — latent-space prediction over temporal windows — for TKGs.

## Adopted in this session (library layer)

- **`regularizers.NormReg`** — BiJEPA's representation-norm regularizer.
  Penalizes `(||z||²/d − 1)²`, closing both the norm-explosion escape of
  symmetric prediction and the collapse-to-zero escape. Composes with
  SIGReg/WeakSIGReg/RDMReg (shape vs scale: orthogonal concerns).
- **`bijepa.BiJEPATrainer`** — joint training of a forward predictor
  (context → target) and a mirrored backward predictor (target → context)
  with cycle-consistency losses `g(f(ctx)) ≈ ctx`, `f(g(tgt)) ≈ tgt`,
  NormReg, and optional SIGReg-family regularization. Auto-mirrors the
  backward predictor from the forward predictor's dimensions.
- Tests encode the intent: cycle terms must contribute to the total loss,
  cycle error and inverse-direction error must tighten with training, norm
  inflation must cost orders of magnitude more than unit-scale embeddings.

## Library-scale A/B evidence (synthetic, CPU)

`examples/bijepa_ab_benchmark.py` — identical forward MLP predictor, data,
and optimizer; only the training objective differs (plain MSE vs BiJEPA's
bidirectional + cycle + NormReg objective). Data: random stable linear
dynamical systems (dim 16, spectral radius ~0.95, noise 0.05), 5 seeds.
Run 2026-07-24 on CPU (torch 2.13):

| Evaluation | Unidirectional MSE | BiJEPA MSE | Wins |
|------------|-------------------|------------|------|
| Cross-system (held-out NEW dynamics) | 0.1969 ± 0.1278 | **0.1852 ± 0.1243** | **5/5 seeds** |
| Same-system future windows | 0.0141 ± 0.0021 | 0.0143 ± 0.0019 | 2/5 seeds (tie within noise) |

Reading: the bidirectional/cycle signal acts as a regularizer that helps
out-of-distribution generalization (~6% MSE, consistent across all seeds)
and costs nothing in-distribution. This is library-scale evidence on
synthetic dynamics — it does **not** establish anything about the production
healthcare TKG; that remains the V6.3 Modal run's question, gated on the
probe suite (Glosa AUC, LOS MAE), not on MSE.

## Deliberately not adopted

- **InfoNCE alignment (SG-JEPA).** The V5 postmortem's central lesson is that
  contrastive/reconstruction objectives conflict with temporal prediction on
  this TKG — epoch 2's auxiliary losses degraded every downstream metric.
  SG-JEPA's speedups come from what V6.2 already does (no edge
  reconstruction, no negative sampling); importing its InfoNCE term would
  reintroduce the V5 failure mode.
- **Spiking context encoder (SG-JEPA).** Hardware-efficiency play; no
  neuromorphic target in jcube's deployment story, and it would fork the
  encoder stack V6.2 warm-starts from.

## What "SOTA" still requires (out of scope for a code session)

The trained production model's metrics (Glosa AUC 0.690, LOS MAE 6.86d, see
`docs/V5_POSTMORTEM.md`) only move with a Modal GPU run. The natural next
experiment — **V6.3** — is:

1. Keep V6.2's loss exactly (dense lookahead + Weak-SIGReg).
2. Add the backward/cycle terms from `BiJEPATrainer` at low weight
   (`cycle_weight ≈ 0.1`) with `NormReg` enabled.
3. Warm-start from the V6.2 checkpoint; verify with
   `verify_v62_epoch1.py`'s protocol (delta check → structural health →
   probes) before promoting.

Risk note: V5 showed auxiliary objectives can degrade the primary one. The
cycle loss is *aligned* with temporal prediction (it is prediction, both
ways) rather than reconstruction, but the V6.3 run must still gate on the
probe suite, not on training loss.
